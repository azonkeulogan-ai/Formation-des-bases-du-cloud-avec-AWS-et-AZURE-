# Formation-des-bases-du-cloud-avec-AWS-et-AZURE-Module un : comprendre ce qu'est le cloud computing. Le cloud désigne l'utilisation de serveurs à distance, accessibles par internet, plutôt que des machines physiques possédées localement. On loue de la puissance de calcul, du stockage, ou des services prêts à l'emploi auprès de fournisseurs comme AWS ou Azure. Trois grands types de services existent : l'infrastructure en tant que service, la plateforme en tant que service, et le logiciel en tant que service. Exercice pratique : identifie un service que tu utilises déjà et détermine s'il repose probablement sur le cloud.



Module deux : créer et sécuriser son premier compte cloud. La création demande un email, une carte de paiement, et quelques informations de base. La sécurité est prioritaire : activer l'authentification à deux facteurs, créer des comptes secondaires à droits limités, et configurer des alertes de facturation dès le départ. Exercice pratique : crée un compte gratuit, active la double authentification, et configure une alerte de facturation à un seuil bas.




Module trois : comprendre le stockage dans le cloud. AWS propose S3, Azure propose Blob Storage, fonctionnant sur le principe de conteneurs appelés buckets. Le coût varie selon la fréquence d'accès aux données. Il faut bien configurer les droits d'accès pour éviter qu'un espace de stockage devienne accidentellement public. Exercice pratique : crée un espace de stockage, téléverse un fichier test, et vérifie que l'accès est privé.




Module quatre : déployer un serveur virtuel. Appelé EC2 sur AWS et Azure Virtual Machines sur Azure, on choisit sa puissance, son système d'exploitation, et ses règles réseau. Un serveur actif reste facturé même sans usage, donc il faut penser à l'arrêter après les exercices. Exercice pratique : déploie un petit serveur, connecte-toi dessus, puis supprime-le.




Module cinq : comprendre les réseaux et la sécurité dans le cloud. Le réseau virtuel privé, VPC sur AWS ou Virtual Network sur Azure, isole les ressources. Des groupes de sécurité définissent les accès autorisés, et la bonne pratique est de n'ouvrir que le strict nécessaire. Le chiffrement des données doit être activé au stockage et au transfert. Exercice pratique : vérifie les règles de sécurité de ta ressource et ferme tout accès non nécessaire.




Module six : gérer les coûts et éviter les mauvaises surprises. La facturation est à l'usage, donc variable. Les tableaux de bord détaillent les coûts par service. Les bonnes pratiques : supprimer les ressources de test inutilisées, choisir une taille adaptée, et profiter des offres gratuites. Exercice pratique : consulte ton tableau de bord et identifie le service le plus coûteux.




Module sept : découvrir les services managés les plus utiles. Des bases de données managées évitent d'installer un logiciel soi-même. Des fonctions à la demande, comme AWS Lambda ou Azure Functions, s'exécutent seulement quand nécessaire, réduisant les coûts. Ces services conviennent bien aux petites équipes sans grandes compétences techniques. Exercice pratique : identifie un besoin simple et cherche le service managé correspondant.




Module huit : construire une première compétence cloud monétisable. Trois pistes : la certification reconnue sur le marché, l'accompagnement de petites entreprises en freelance, ou la création de contenu pédagogique comme cette formation. La pratique régulière sur des projets concrets reste essentielle. Exercice pratique : choisis une piste et définis une première étape concrète pour le m

ois qui vient.
